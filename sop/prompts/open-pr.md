# Open the PR

Write the summary part of this branch's pull request body, in Markdown, from `git log` and `git diff` against the base. Start with a `## Problem` section that says what the item asked for and why, then a `## What changes` section, a few lines long. Name the files a reviewer should read first.

Write only the summary. Don't include the item reference or the Definition of Done checklist, because the factory adds both. Don't change any file.
