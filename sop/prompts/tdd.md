# Green

Make the item's scenarios pass by writing the code they describe, one unit at a time: write a failing unit test, make it pass, then refactor.

- Don't edit the locked feature files. A change to one fails this stage.
- Every scenario in the suite must pass, the earlier items' included, and so must the repo's test and lint commands.
- The repo's Definition of Done follows. Meet every line you can.
- Commit your work when you're done.
